# Make It Rain 2.1.2

## What's Changed

- **Saved import presets.** Capture and reuse full bulk-import configurations, with dedicated command-palette commands for each saved preset.
- **Optional Raindrop group folders.** Import paths can omit Raindrop group folders when that organization is not wanted.

## Upgrade notes

No migration is required. Update the plugin files in your vault, then restart Obsidian if it is already running.
